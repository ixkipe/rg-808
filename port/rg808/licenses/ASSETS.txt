RG-808 sample kit
=================
The 11 WAV files in this kit are selected and renamed from the "Roland TR-808"
sample pack supplied with the project source:

  bd.wav <- TR-808Kick07.wav   sd.wav <- TR-808Snare01.wav
  lt.wav <- TR-808Tom01.wav    mt.wav <- TR-808Tom04.wav   ht.wav <- TR-808Tom06.wav
  ch.wav <- TR-808Hat_C01.wav  oh.wav <- TR-808Hat_O01.wav
  cl.wav <- TR-808Clave.wav    cp.wav <- TR-808Clap01.wav
  cb.wav <- TR-808Cow.wav      cy.wav <- Crash-02.wav

See tools/prepare-assets.ps1 for the mapping (easy to reassign).
Remix/redistribution terms of the original pack: unknown — the pack was
provided to this project by its owner. If this port is published publicly,
confirm the pack's licence first.
