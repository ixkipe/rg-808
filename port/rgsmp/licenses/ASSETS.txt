RG-808 sample kit
=================
74 WAVs shipped as <track>NN.wav variant families, copied from the
"Roland TR-808" sample pack supplied with the project source:

  bd01..16   <- TR-808Kick01..16
  sd01..16   <- TR-808Snare01..16
  lt/mt/ht01..07 <- TR-808Tom01..07  (same family on each tom track)
  ch01..05   <- TR-808Hat_C01..05
  oh01..03   <- TR-808Hat_O01..03
  cl01..02   <- TR-808Clave, Claves
  cp01..03   <- TR-808Clap01..02, Clap
  cb01..02   <- TR-808Cow, Cowbell
  cy01..06   <- TR-808Ride01..04, Crash-01, Crash-02

Default pick per voice: see src/engine.c (dflt) and tools/prepare-assets.ps1.
Remix/redistribution terms of the original pack: unknown — the pack was
provided to this project by its owner. If this port is published publicly,
confirm the pack's licence first.
