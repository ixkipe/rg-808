# RG-SMP

An 11-track sample drum machine for PortMaster handhelds: a 1-16-step
sequencer, recursive WAV sample browser, one sample per track, per-step
accents, sample-accurate timing, a 200-slot pattern library, 512-bar song
chains with WAV export, a master effects chain, per-track mute and held R1
punch-in FX. Written in C with SDL2; runs natively at 640x480.

> **Disclaimer: this project was made with AI.** All of the source code, build
> and packaging tooling, documentation and planning in this repository were
> generated by an AI coding agent (OpenCode, running the Qwen3.8 Flash model)
> working for the project owner, who provided the sample packs, made the design
> decisions and performed all testing on real hardware. Nothing here was
> hand-written by a human programmer. Evaluate the code with that in mind.

## Sample folders

WAV files live under `assets/wav/` and may be nested. The sample browser walks
directories recursively; `..` is always the first entry inside a subdirectory.
A track left without a sample is silent. If a pattern references a WAV that is
no longer present at startup, the track stays silent and its header shows a
yellow `!` beside the red mute `M`.

Samples are loaded only when a pattern or song needs them. Each sample is
limited to 10 seconds; a song sample bank is capped at 128 unique files / 64 MB
and refuses to start if the chain exceeds that budget.

The first launch installs a factory 909 groove named `DEFAULT` into slot 001
(130 BPM). It is written only once; deleting patterns later does not restore it.

## Controls

| Button | Action |
|--|--|
| D-Pad | Move cursor |
| A | Cycle step: off / on / accent |
| B | Clear step (back in menus) |
| X | Hear selected track |
| Y | Mute / unmute selected track |
| START | Play / stop |
| SELECT | Menu (tempo, swing, pattern length, ratchets, sample browser, effects, save, pattern library, song mode, clear, quit) |
| L1 / L2 / R2 | Shoulder shortcuts (hold; on-screen hint shows each direction) |
| R1 + D-Pad / A B X Y | Held punch-in FX (one at a time, quantized to the next 16th) |

Shoulder shortcuts (hold + D-pad):
L1+Left = tempo, L1+Right = swing, L1+Up = pattern length,
L1+Down = ratchet notes, L2+Left = pattern library, L2+Right = song mode,
L2+Up = sample browser, R2+Up = drive FX, R2+Left = modulation FX,
R2+Down = delay FX, R2+Right = reverb FX. Other L2 combinations are reserved.
Pressing a shoulder shows the hint overlay; releasing it hides the overlay.

R1 punch-in FX: hold R1 and press Left/Right/Up/Down for 1/4, 1/8, 1/16 or
1/32 stutter loops; A = 1/4 rewind, B = 1/16 gate, X = tape stop (one 1/8
note to silence), Y = phone filter. The overlay mirrors the SP controls: D-pad
on the left, face buttons on the right (X top, A right, B bottom, Y left). The
effect starts on the next 16th, only one is active at a time, and release
crossfades back to live audio. It works in pattern and song playback and is
not included in WAV export.

Mute: Y toggles a performance mute for the selected track; X still auditions
it. Muted rows are tinted and marked with a red M. Mutes apply to live and song
playback, cut ringing hits immediately, and are not saved with the pattern.

Sample browser (menu -> SAMPLE BROWSER, or L2+Up): browse `assets/wav`
recursively. Directories are entered with A; WAV files are assigned to the
current track and auditioned. X auditions without assigning, B returns to the
sequencer, D-pad scrolls and left/right pages. The browser remembers the last
directory for the session.

Ratchet notes (menu -> RATCHET NOTES) turn any step into a 2x / 3x / 4x roll or
a flam; A cycles the mode, the cell shows its digit. Swing (menu -> EDIT SWING)
shuffles every even 16th, 0-100%. Pattern length (menu -> PATTERN LENGTH, or
L1+Up) plays 1-16 of the 16 steps; steps past the end stay stored but dimmed.
Each track keeps at most two live voices, so fast repeated hits do not pile up
indefinitely.

Effects (menu -> EFFECTS): per-pattern master chain
drive -> modulation -> delay -> reverb. Drive is selectable as bitcrusher,
overdrive or compression; modulation as flanger or phaser. Delay can be set in
milliseconds or tempo-synced to straight, triplet and dotted divisions.
Up/down selects, left/right adjusts, A toggles the selected stage or sync.
FX are saved with the pattern; `conf/fx.txt` is the fallback for old patterns.

Pattern library (menu -> PATTERN LIBRARY): 200 numbered slots. D-Pad selects,
left/right pages, A loads, B returns; SELECT opens save/copy/rename/delete.
The header shows the active slot, and edits autosave into it. Patterns are
stored in `conf/patterns/` with an `index.txt`.

Song mode (menu -> SONG MODE, or L2+Right): chain up to 512 bars of pattern
slots. A picks the pattern for a bar, X jumps to the playing bar, START
plays/stops, SELECT opens insert/delete/move, play-from-here, loop, export
WAV, save and clear. Each bar keeps its pattern's BPM/swing/length, sample
assignments and FX. EXPORT WAV writes `conf/song.wav` (44.1 kHz/16-bit stereo)
with a progress bar; the chain lives in `conf/song.txt`.

## Compile

```
docker build -t rg808build tools/portmaster-build
docker run --rm -v "$PWD:/src" rg808build     # writes dist/rgsmp.zip
```
Native dev builds (Windows MinGW / Linux) use the top-level CMakeLists with
`-DRG_MACHINE=smp`. The tracked 808 kit is part of the shared tree; place your
sampler packs in an ignored subdirectory such as `assets/wav/909` before
building the port zip.
