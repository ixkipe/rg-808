# RG808

A Roland TR-808 clone for PortMaster handhelds: a 1-16-step, 11-track drum
machine with per-step accents, sample-accurate sequencing, one-tap sample
selection per voice (kit mode), a 200-slot pattern library, song chains with
WAV export, a per-pattern master effects chain (selectable drive and
modulation, tempo-synced delay, reverb), per-track mute and held R1 punch-in
FX, written in C with SDL2. Runs natively at 640x480.

**RG-808 1.1** (2026-11-27). New in 1.1: USB-MIDI input (clock and transport
sync, song mode follows the master), per-track pitch with time stretch and
pattern-wide sample start/end cuts. **RG-808 1.0** was the first stable release
(2026-11-15); RG-SMP ships as 1.1 from the `sampler` branch.

**RG-SMP 1.1** (2026-11-27) ships from the `sampler` branch (1.0 was
2026-11-15).

## Controls

| Button | Action |
|--|--|
| D-Pad | Move cursor |
| A | Cycle step: off / on / accent |
| B | Clear step (back in menus) |
| X | Hear selected voice |
| Y | Mute / unmute selected voice (sequencer) |
| START | Play / stop |
| SELECT | Menu (tempo, swing, pattern length, ratchets, kits, effects, save, pattern library, clear, quit) |
| L1 / L2 / R2 | Shoulder shortcuts (hold; on-screen hint shows each direction) |
| R1 + D-Pad / A B X Y | Held punch-in FX (one at a time, quantized to the next 16th) |

Shoulder shortcuts (hold + D-pad):
L1+Left = tempo, L1+Right = swing, L1+Up = pattern length,
L1+Down = ratchet notes, L1+X = pitch (transpose the selected track),
L1+B = sample start/end (slice the step),
L2+Left = pattern library, L2+Right = song mode,
L2+Up = sample/kit selection, L2+Down = export song to WAV (with a
confirmation page), R2+Up = drive FX, R2+Left = modulation FX,
R2+Down = delay FX, R2+Right = reverb FX. Pressing a shoulder shows the hint
overlay; releasing it hides the overlay immediately.

Pitch: L1+X opens the pitch page for the selected track. Up/down move one
semitone, left/right a whole octave, A auditions, B returns; the range is
-24..+24. The sample is time-stretched, so its length - and the beat - stays
put. The interval is saved with the pattern and shown next to the track label
(+7); each song bar can transpose on its own.

Slice: L1+B opens the start/end page for the selected track. One cut per track
- every step of the pattern plays it. Left/right or A switches between START
and END, up/down nudges the value (hundredths of a percent, coarser while
held), X auditions. The cut is stored with the pattern (`TRM <track> <start>
<end>`); older per-step `TRM` lines still load and migrate to the first cut
they contain.

USB-MIDI in (1.1): plug a USB-MIDI master into the Type-C port and the machine
syncs to it - MIDI clock drives the tempo, START/STOP/CONTINUE drive the
transport and SPP positions the song. On the song page the armed chain plays
on the master's START instead of the pattern: a looping song repeats until
STOP, a non-looping one ends in standby and re-arms for the next START. Your
own tempo is restored when the device disconnects, and a tempo-synced delay is
bypassed while the clock drives us. The header shows a red MIDI chip while
synced. Verified with a Roland T-8; plug the master in while the app runs so
the reader can claim it.

R1 punch-in FX: hold R1 and press Left/Right/Up/Down for 1/4, 1/8, 1/16 or
1/32 stutter loops; A = 1/4 rewind, B = 1/16 gate, X = tape stop (one 1/8
note to silence), Y = phone filter. The overlay mirrors the SP controls: D-pad on the left, face buttons
on the right (X top, A right, B bottom, Y left). The effect starts on the next
16th, only one is active at a time, and release crossfades back to live audio.
It works in pattern and song playback and is not included in WAV export.

Mute: Y toggles a performance mute for the selected instrument in the
sequencer; X still auditions it. Muted rows are tinted and marked with a red
M. Mutes apply to live and song playback, cut ringing hits immediately, and
are not saved with the pattern. Swing (menu -> EDIT SWING) shuffles every even
16th, 0-100%. Pattern length
(menu -> PATTERN LENGTH, or L1+Up) plays 1-16 of the 16 steps; steps past the
end stay stored but dimmed. Ratchet notes
(menu -> RATCHET NOTES) turn any step into a 2x / 3x / 4x roll or a flam;
A cycles the mode, the cell shows its digit. Kit mode (menu -> SELECT KITS):
each row is an instrument, the numbered columns are that instrument's
sample variants. A picks and auditions, X auditions, B returns. All picks
are saved with the pattern.

Effects (menu -> EFFECTS): per-pattern master chain
drive -> modulation -> delay -> reverb. Drive is selectable as bitcrusher,
overdrive or compression; modulation as flanger or phaser. Delay can be set
in milliseconds or tempo-synced to straight, triplet and dotted divisions.
Up/down selects, left/right adjusts, A toggles the selected stage or sync.
FX are saved with the pattern; `conf/fx.txt` is the fallback for old patterns.

Pattern library (menu -> PATTERN LIBRARY): 200 numbered slots. D-Pad selects,
left/right pages, A loads, B returns; SELECT opens save/copy/rename/delete.
The header shows the active slot, and edits autosave into it. Patterns are
stored in `conf/patterns/` with an `index.txt`; a v1 `conf/pattern.txt` is
imported into slot 001 on first launch.

Song mode (menu -> SONG MODE, or L2+Right): chain up to 512 bars of pattern
slots. A picks the pattern for a bar, X jumps to the playing bar, START
plays/stops, SELECT opens insert/delete/move, play-from-here, loop, export
WAV, save and clear. Each bar keeps its pattern's BPM/swing/length/kit.
EXPORT WAV writes `conf/song_<tempo>_<yyyymmdd>_<hhmmss>.wav` (44.1 kHz/16-bit
stereo) with a progress bar; the chain lives in `conf/song.txt`. The tempo tag
is bar 1's BPM, with `_` before a fractional part (`90_5`). Existing exports
are never overwritten: a repeated name gets `_2`, `_3`, ... appended.

## Compile

```
docker build -t rg808build tools/portmaster-build
docker run --rm -v "$PWD:/src" rg808build     # writes dist/rg808.zip
```
Native dev builds (Windows MinGW / Linux) use the top-level CMakeLists.
